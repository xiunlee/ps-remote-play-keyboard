# 上班不要玩 — 實體 PS4 手把鍵盤中繼測試版

**狀態：2026-10-29 已切換至「上班不要玩」0.1.0-alpha.3，使用者回報新版測試正常。** 自訂鍵儲存後重開、完整按鍵清單、各語言實際操作、不同電腦與驅動還原尚未逐項驗證。

這個程式接收實體手把經 USB/IP 傳來的按鍵報告，將鍵盤狀態合併進每一份新的實體報告。它不產生獨立的假手把，不把鍵盤寫入手把的輸出命令，也不載入 Sony 程序。

資料路徑為：實體 DS4 → 已另外設定的 usbipd-win → 本程式僅限本機的中繼 → 已另外設定的 usbip-win2 → Windows／官方 Remote Play。匯入 Windows 的 USB 拓樸仍會改變；本機的正常操作回報不等於所有電腦或手把都已相容。

## 本程式範圍

- 僅在本視窗或指定安裝位置的官方 Remote Play 前景接收實體鍵盤事件。
- F8 啟用／暫停；開始時暫停；失焦、Ctrl／Alt／Windows 快捷鍵、通道中斷與兩秒無有效資料都會釋放鍵盤操作。
- 每一份 64-byte、ID `01` 的實體按鍵資料都重新合併，放開按鍵後恢復當下實體手把狀態。右搖桿與未映射資料保留。
- 中繼從實體 USB 設定描述確認指定通道是目前啟用的 HID interrupt-IN、64-byte 通道後，才把按鍵報告交給合併器；確認前鍵盤保持暫停。識別、控制、Feature、驗證與輸出封包由中繼轉送。參見 [中繼實作](../../research/physical-usb-relay/)。
- 不安裝／綁定驅動、不自動接管 USB、不呼叫 USBip attach／detach、不重啟 Remote Play、不要求 PSN 登入、不記錄原始按鍵或驗證封包。

**本程式單獨啟動不會使實體手把進入中繼。** 必須先完成另外的實體裝置綁定與 USB/IP 匯入程序。這些步驟會影響手把連線，不應拿未核對的 bus ID 直接操作。

本機已完成實體綁定後，可透過桌面「PS 鍵盤中繼」捷徑啟動。捷徑使用 `Open-PhysicalRelay.ps1` 核對原本的手把與分享紀錄，取得重開機後的新位置，必要時啟動既有服務，再開啟中繼並接入手把。鍵盤維持暫停，需按 F8 啟用。它不安裝或重新綁定驅動，也不啟動 Sony；服務停止時可能出現 Windows 管理員確認。

`Open-PhysicalRelay.ps1 -CheckOnly` 只檢查既有設定，不啟動服務、程式或 USB 匯入。若既有匯入裝置尚未清理而原程式已結束，啟動器會停止並回報，不自行解除其他裝置。這仍是目前電腦的測試啟動流程，尚非一般發行版安裝程式。

## 建置與離線驗證

```powershell
.\src\physical-keyboard\Build.ps1 -Zig '完整 zig.exe 路徑' -RunTests
```

使用 Windows .NET Framework x64 編譯器及既有 native merge core。輸出預設在使用者 `.pskeyboard-tools\physical-keyboard-builds` 下的全新資料夾，避免覆蓋正在使用的版本；也可明確指定另一個 `-OutputDirectory`。測試驗證合併、按鍵生命週期、設定儲存與語言選擇，不開啟任何裝置或網路。

2026-10-28：含 `EndpointVerified` 檢查的應用程式以警告視為錯誤成功建置，合併／原生 DLL／按鍵生命週期與啟動參數解析檢查通過。應用程式尚未開啟，視覺呈現、實體中繼及 PS5 操作均未驗收。

`PSKeyboard-Physical.exe` 可接受一個可選參數作為手把 bus ID 欄位的初值；不會自動啟動中繼或啟用鍵盤。

明確指定 `PSKeyboard-Physical.exe --start-relay <已核對的實體 bus ID>`，會在視窗與 F8 暫停鍵設定成功後，自動啟動本機中繼，方便無法點擊視窗的設定流程。鍵盤仍保持暫停，仍需有效實體通道與資料到達後才可按 F8。這個選項不會綁定、匯入或挑選 USB 裝置，也不會啟動 Sony 程序；目前使用畫面預設的第一代 DS4 型號與通道 4。

可另加 `--status-file "C:\已存在的資料夾\status.json"`，明確啟用本機狀態檔；未指定就不寫檔。僅接受本機磁碟完整 `.json` 路徑，拒絕相對路徑、網路分享與替代資料串流。獨立背景執行緒每 500 毫秒以同資料夾暫存檔原子替換，僅記錄 `pid`、`enabled`、`attached`、`endpointVerified`、`inputReports`、`mergedReports`、`failure`，不記錄按鍵、原始 USB 資料或裝置路徑。`failure` 只輸出預先定義的錯誤代碼，不寫入任意例外文字。此檔只供本程式診斷，不能證明 Sony／PS5 接受輸入。

暫停時若已有一份按鍵報告正在合併中，該份可能先完成；後續報告立即改用新讀到的實體狀態，不會重送先前合併結果。

## 操作設定

填入經核對的實體手把 bus ID、產品型號與 interrupt-IN 資料通道。第一代 DS4 為 `054C:05C4`，第二代為 `054C:09CC`；資料通道預設 4，仍需依裝置檢查結果確認。

「啟動中繼」只監聽 `127.0.0.1:33251`，上游固定 `127.0.0.1:3240`。外部匯入完成並持續收到有效按鍵報告後才可按 F8。新版以狀態燈和文字顯示通道健康；綠燈代表最近有有效實體資料，不表示 PS5 已連線。報告數量留在選用的診斷狀態檔中。

新版可透過「按鍵設定」修改下列 22 個動作；F8 固定保留為啟用／暫停。設定儲存在 `%LOCALAPPDATA%\PSKeyboard\bindings.json`。編輯期間暫停鍵盤，儲存或取消後需重新啟用，不會停止實體手把中繼。這張表是預設值，並非不可修改的限制。

介面隨 Windows 顯示語言選擇繁中、簡中、英、日、韓、德、法、西、巴西葡語；未支援語言使用英文。設定檔、狀態燈與其他手把／Mac 的範圍見 [發布前功能](../../docs/PRODUCT-SCOPE.md)。

## 受控安裝與還原工具

這兩個 PowerShell 工具不會由 GUI 自動執行，需系統管理員權限及明確的實體裝置切換授權：

- `Install-Exporter.ps1`：只接受指定雜湊及有效簽章的 usbipd-win 5.3.0 安裝檔；拒絕覆蓋既有 usbipd／VirtualBox USB 驅動。安裝後停用原廠的區網開放規則，新增只限該程式與連接埠的非本機阻擋規則，再確認服務。此步驟不綁定手把。
- `Switch-PhysicalDriver.ps1`：以本機保存的實體裝置基線核對完整裝置與父裝置，只切換這一隻 DS4。還原需提供本次綁定取得的 `ExpectedPersistedGuid`，避免解除他人後來建立的分享。

兩者都不會重新啟動 Windows。需讀取結果 JSON 判斷成功、失敗或要求重開機，不能單憑視窗消失判定成功。若出現重開機要求，停止掛載及實測。完整步驟與限制見[實機測試準備](../../research/physical-usb-relay/FEASIBILITY.md)。

2026-10-28 更新後，合併、按鍵生命週期、參數解析及診斷檔檢查共 110 項通過。這些是程式測試，不代表實體 USB 中繼或 Sony 已驗收。

## 新版畫面預覽與驗收

新版加入自訂按鍵、狀態燈及九語系資源。2026-10-29 離線檢查包含原有 110 項合併測試、170 項設定與改鍵生命週期測試、38 項既有按鍵測試、78 項編輯器互動回歸測試及 2,255 項語言資源／自動選擇檢查。九種語言的主畫面和按鍵設定視窗均已產生預覽並檢視。當日切換新版後使用者回報測試正常，並核對到鍵盤合併輸出；母語翻譯校閱、高 DPI、錯誤對話與自訂鍵逐項實機驗收仍待完成。

在獨立建置目錄執行以下模式，只繪製本程式的預覽圖，不讀寫使用者設定、不建立鍵盤掛鉤或實體中繼。預覽採用透明、不取得焦點的測試視窗，不操作 Sony 視窗。

```text
PSKeyboard-Physical.exe --render-preview C:\已有資料夾\main.png --preview-language zh-TW
PSKeyboard-Physical.exe --render-editor-preview C:\已有資料夾\editor.png --preview-language de-DE
```

預覽圖的斷線／暫停顯示是測試狀態，不是目前正在運作版本的診斷結果。新建置不附指向既有安裝的桌面啟動器，避免誤開舊版；現有桌面捷徑保持不變。
