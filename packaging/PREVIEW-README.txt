PS 鍵盤中繼 — 商品化準備用內部測試包

這不是正式販售版本，也不是能在新電腦直接安裝的一鍵安裝包。
目前使用者已回報在自己的電腦測試正常；其他電腦尚未驗收。

本包包含：自製中繼程式、原生按鍵合併元件、唯讀狀態檢查工具、
操作者用的安裝／還原腳本，以及檔案校驗資訊。
沒有包含任何人的裝置記錄、帳號、PSN 資料或第三方驅動安裝檔。

現有使用者請繼續使用桌面的「PS 鍵盤中繼」。
不要把這個包覆蓋到正在執行的版本，也不要隨意執行 operator-tools。
直接開啟本包的程式不會自動綁定實體手把。

控制方式：
新版「按鍵設定」可自訂以下按鍵、清除、恢復預設並儲存。
編輯期間鍵盤暫停，完成後需再啟用；F8 為保留按鍵。
設定儲存在目前 Windows 使用者的 LocalAppData\PSKeyboard 資料夾。
F8：啟用／暫停鍵盤
WASD：左搖桿；方向鍵：十字鍵
I/J/L/K：三角／方塊／圓圈／叉
Q/E：L1/R1；U/O：L2/R2；1/2：L3/R3
Enter：Options；Backspace：Share；T：觸控板按下；P：PS 鍵

介面依 Windows 顯示語言自動選擇繁中、簡中、英、日、韓、德、法、西、
巴西葡語；其他語言使用英文。維護腳本與文件尚未完整翻譯。
手把綠燈代表資料正常，不代表 PS5 連線成功。鍵盤是否啟用另有狀態。
目前只確認有線 DS4 第一代的本機試用，其他手把、免手把與 Mac 未支援。
新版自訂按鍵與多語介面尚待實機驗收，不應中斷既有遊戲連線來套用。

Check-Status.ps1 只讀取中繼狀態，不關閉 Remote Play、不修改裝置。
它查的是目前已部署的 physical-keyboard-preview，不是這個新包。
舊版桌面啟動器指向既有安裝，因此新包不附該啟動器，避免誤開舊版。
停止中繼可能讓手把暫時不能使用；目前還原需由操作者核對裝置後處理。
尚待完成：新電腦設定精靈、可靠停止與還原、移除流程、相容性測試、
第三方散布授權、簽章及正式販售設定。
