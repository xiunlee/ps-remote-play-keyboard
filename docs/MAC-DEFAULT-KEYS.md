# Mac 預設鍵位

「上班不要玩／Three Cats Keybridge」Mac **0.1.3**使用下列預設鍵位，亦可在「按鍵與連點設定」改綁；主畫面會顯示儲存後的實際設定。預設適合 Mac 精簡鍵盤，不需要 Fn、功能鍵、Home、End、Insert 或 Page Up／Down。

在 App 按「連接並啟用控制」，等待元件準備與手把連接完成，再切回 PS Remote Play。整合流程的驗證進度與首次安裝方式見 [Mac 安裝說明](MAC-INSTALL.md)。

四個面鍵依手把的菱形位置排列：

```text
             I → △ 三角形

 J → □ 正方形             L → ○ 圓圈

             K → × 叉號
```

**I＝△、J＝□、K＝×、L＝○。** 遊戲要求按圓圈時按 **L**；Remote Play 在前景時，**Esc** 用於切換鍵盤控制的啟用／暫停。

| PS5 動作 | Mac 按鍵 |
| --- | --- |
| 左搖桿上／下／左／右 | W／S／A／D |
| 十字鍵上／下／左／右 | ↑／↓／←／→ |
| △ 三角形 | I |
| □ 正方形 | J |
| × 叉號 | K |
| ○ 圓圈 | L |
| L1／R1 | Q／E |
| L2／R2 | Z／C |
| Create／Options | Tab／Return（Enter） |
| L3／R3 | F／空白鍵 |
| PS 鍵 | P |
| 觸控板按下 | T |
| 啟用／暫停 | Esc |

22 個遊戲動作與 Esc 共使用 23 個不同的鍵。預設連點關閉；右搖桿與觸控滑動沒有鍵位。

只有 PS Remote Play 在前景時才輸出遊戲控制。切換視窗或按住 Command／Control／Option／Shift 時會清除輸出；切回後需放開並重新按下按鍵。Esc 在其他程式中保留原用途。

此配置使用 macOS 實體鍵碼，使用 Mac 專用設定格式；不讀取、轉換或覆寫 Windows 鍵位。原 F8 啟用／暫停已改為 Esc。
