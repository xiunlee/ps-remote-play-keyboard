## Features

1. Three Cats Keybridge is a keyboard-control and virtual-controller tool for the supported remote-play environment listed below. No physical controller is required.
2. Customize keys for 22 controller actions and configure auto-repeat separately for each action.
3. The interface follows the preferred macOS language and supports English, Traditional Chinese, Simplified Chinese, Japanese, Korean, German, French, Spanish and Brazilian Portuguese.
4. Free and open source by xiunlee. Optionally [contribute toward food for the cats](https://www.paypal.com/ncp/payment/HAW9YBJXNEMFW) or [send feedback](mailto:xiun1019@gmail.com).

## Important notes

1. Keyboard input and auto-repeat work only while official PS Remote Play is in the foreground. Switching windows stops auto-repeat; Esc enables or pauses control.
2. Designed for 2D games, especially menu- and direction-based JRPGs. Mouse aiming and right-stick direction mapping are unavailable; it is unsuitable for 3D games that require flexible camera movement or fine analog control.
3. On the first connection, required components are downloaded and verified directly from VirtualHere and run in its free single-device mode. Other VirtualHere installations are not modified. A connected device indicator does not prove that the PS5 received input; compatibility can vary between releases.
4. This App uses a project self-signed certificate. It is not signed with Apple Developer ID or notarized by Apple. Read the included guide and use the normal macOS opening and Accessibility authorization workflows.
5. This is an independent project, not an official Sony product, and is not affiliated with or endorsed by Sony.

## Supported system

1. An Apple Silicon Mac running macOS 15 or later, with Sony's official PS Remote Play connected to a PS5. Intel Macs are not currently supported.
2. Internet access is required to obtain components for the first time, and the App needs Accessibility permission. Native helpers and the runtime environment are bundled; original VirtualHere components are downloaded separately from their publisher. Users do not need Python, Go, Swift, Docker, Parallels or an Apple developer account.
