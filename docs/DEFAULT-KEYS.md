# 預設鍵位（0.1.0-alpha.7 起）

按一般鍵盤的左右手位置安排：左手放 WASD，右手放方向鍵。依使用者要求，右手方向鍵對應手把右側的四個圖形按鈕，不是十字方向鍵。

| 手把功能 | 鍵盤 |
| --- | --- |
| 左搖桿上／下／左／右 | W／S／A／D |
| △／□／×／○ | ↑／←／↓／→ |
| L1／L2 | E／Q |
| R1／R2 | Delete／Page Down |
| 十字方向鍵上／下／左／右 | Home／End／Insert／Page Up |
| L3／R3（按下搖桿） | F／空白鍵 |
| Create／Share | Tab |
| Options | Enter |
| 觸控板按下 | R |
| PS | F1 |
| 啟用／暫停鍵盤 | F8 |

方向鍵上方的六鍵區排列如下，十字方向保留相對位置；Delete 與 Page Down 留給右肩鍵。

```text
Insert        Home          Page Up
十字左        十字上        十字右

Delete        End           Page Down
R1            十字下        R2

              ↑ △
        ← □   ↓ ×   → ○
```

F 靠近左手移動區，空白鍵由拇指按 R3，R 為觸控板按下；較少用的 PS 放在 F1，避免佔用主要操作區。精簡鍵盤若沒有六鍵區，可在按鍵設定中自行改鍵。右搖桿視角移動仍未加入，R3 只代表按下右搖桿。

## 套用方式

- 沒有已儲存設定時，新版直接使用這組預設。
- 已有自訂設定時，更新程式會保留原鍵位及連點。要採用新排列，開啟「按鍵與連點設定」→「恢復預設」→「儲存」。
- 「恢復預設」同時將每鍵連點關閉、間隔回到 100 毫秒；需要連點時再選擇個別模式與間隔。
- 編輯後切回 Remote Play，再按 F8 啟用。只在官方 Remote Play 前景處理鍵盤；切窗會停止並清除連點。
