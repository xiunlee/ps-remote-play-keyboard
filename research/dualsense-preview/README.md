# 上班不要玩：DualSense 鍵盤與連點

alpha.9 的四種方案已獲使用者回報均能操作官方 Remote Play 裡的 PS5。依指定，alpha.10 固定使用第二種 **一般 DualSense／純手把**，整合既有 22 動作改鍵與每鍵連點功能。沿用 **usbip-win2 0.9.8.1**。依最新空間需求，本機只留最新交付版本；歷史原始碼、PS4 實作與版本標籤繼續保留。

## 使用方式

1. 保持 Sony Remote Play 開啟，先正常退出舊版「上班不要玩」。兩版不能同時接管 F8。
2. 開啟本版 `PSKeyboard-DualSensePreview.exe`，按「連接手把」。啟動不自動接入，鍵盤控制先暫停。
3. 切回官方 Remote Play，按 **F8** 啟用；再按 F8 可暫停。實際鍵位沿用個人設定。未更動預設時，十字上下是 **Home／End**，叉鍵是 **↓**。
4. 要改鍵或連點，按「按鍵與連點設定」，選取動作後設定；**按儲存才套用與寫入**，取消保留原設定。編輯及儲存後保持暫停，切回 Remote Play 再按 F8。
5. 結束時正常中斷或退出。若清理未確認，程式會阻擋重新接入；回報顯示訊息，不重開 Remote Play、不改驅動。
6. 本機舊版清除後不再提供舊版捷徑；若需要回退，依歷史標籤及建置紀錄重新準備，不更動目前驅動。

| 功能 | 用法 |
| --- | --- |
| 22 動作改鍵 | 選取動作後設定新鍵，可清除；重複鍵、F8 等保留鍵會拒絕 |
| 關閉連點 | 一般按住／放開操作 |
| 按住連點 | 按住該鍵時重複，放開停止 |
| 按一下啟停 | 按一次啟動，再按一次停止；切窗或 F8 也會清除 |
| 間隔 | 每鍵 20–5000 毫秒，預設 100 毫秒；遊戲可能忽略很短的脈衝 |
| 恢復預設 | 先改編輯中的草稿，連點全關、間隔 100 毫秒；儲存才生效 |

畫面的連線燈表示目前 Windows 輸出通道，並非自動偵測 PS5 畫面是否接受操作。alpha.9 的成功回報不替代 alpha.10 新設定流程、長時間及重開機測試。

## 保留與限制

- 不安裝、更換或降級驅動，不自行停止、重啟或更新 Sony Remote Play，不要求 PSN 帳密。
- 開啟程式只載入既有設定，不重設；僅使用者按儲存才原子更新個人設定檔。沿用格式 2，保存失敗不替換目前使用的設定。
- 鍵盤與連點只在官方 Remote Play 前景生效；切窗清除連點，F8 暫停。連線或輸出失敗即停用控制。
- 每次只接一個本程式建立的裝置；只移除自己核對過的 bus／port。使用獨立 loopback `33641/33642`，不使用 alpha.8 的通訊埠。
- 本版移除 alpha.9 的 30 分鐘自動結束限制；退出或失連時仍執行停止與清理。尚未完成長時間、重開機、音訊、觸覺或自適應扳機驗收。
- 個人按鍵設定與備份獨立保留；本機清舊不刪歷史標籤。本包不是正式公開 Release，也不啟用付費服務；第三方元件未完成正式再散布審查。
